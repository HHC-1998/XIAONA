# 2026年9月11日所遇问题及解决方案

## 一、仓库从未初始化 git，无 .gitignore：.env 真实密钥面临泄露风险（推送前清理）

### 问题现象

用户打算把项目推送到 GitHub，要求先做一次「代码干净度」体检：哪些该 ignore、哪些是冗余可删。扫描后发现当前目录**既不是 git 仓库、也没有 `.gitignore`**——一旦直接 `git init && git add .`，`.env` 里的真实凭据会原样进入首个提交。

### 根因分析

1. **无 `.gitignore`**：仓库从未初始化 git（`git rev-parse` 报 `not a git repository`），自然也没建忽略规则，`.env` 与构建产物都处于「可被 add」状态；
2. **`.env` 是真实值而非占位符**：实测 `DB_PASSWORD`(11)、`NEO4J_USER`(5)、`NEO4J_PASSWORD`(11)、`FEISHU_APP_ID`(20)、`FEISHU_APP_SECRET`(32)、`FEISHU_VERIFY_TOKEN`(32)、`FEISHU_ENCRYPT_KEY`(32)、`FEISHU_BOT_OPEN_ID`(35) 均为真实凭据（仅 `OPENAI_API_KEY` 为空）；
3. **冗余堆积**：
   - `XIAONA/`（嵌套目录）内含**孤儿 git 仓库** `XIAONA/.git`——只有 1 个 commit `2de8100 Initial commit`、无 remote、`git ls-files` 仅一个 `.gitattributes`（LF 归一化模板）。留着会让外层仓库把它当嵌套仓库/submodule 处理；
   - `backend/xiaona.db` 155 KB 陈旧 SQLite（PostgreSQL 迁移前遗留），全仓 **0 处引用**；表内除 `data_source_configs` 3 行测试夹具（`user-a`/`user-b`、`etsy-k...`、`key-x`）外全为空；
   - `plan_extract.txt` 8.2 KB 临时提取稿；
   - 9 个 `__pycache__/`（含 `cli/__pycache__/xiaona.cpython-314.pyc`）；
   - 体积大头 `frontend/node_modules` **125.7 MB**、`frontend/dist` 1.8 MB。
4. **源码本身干净**：全仓扫描（*.py/*.js/*.jsx/*.yml/*.json/*.md/*.txt/*.conf，排除 node_modules/dist/__pycache__）**未发现**硬编码 `sk-`/`AKIA`/`ghp_`/私钥或字面量密码。

### 解决方案

**1. 新建根级 `.gitignore`**（此前不存在），分组覆盖：
- 密钥类：`.env` / `.env.local` / `.env.*.local`，并用 `!.env.example` **显式豁免**示例文件——**不可写成 `.env*`**，否则会把需要提交的 `.env.example` 一起挡掉；
- Python：`__pycache__/`、`*.py[cod]`、`*.egg-info/`、`.venv/`、`venv/`；
- 前端：`node_modules/`、`frontend/dist/`（dist 由 `frontend/Dockerfile` 构建阶段 `npm run build` 重建，`start.py` 只走 `docker compose up --build`，不读本地 dist）；
- 运行时产物：`artifacts/`、`backups/`（artifacts 为 compose bind mount，见 AGENTS.md「产物落盘」）；
- 数据库/日志：`*.db`、`*.sqlite`、`*.sqlite3`、`*.log`；
- 系统/编辑器：`.DS_Store`、`Thumbs.db`、`desktop.ini`、`.idea/`、`.vscode/`、`*.swp`。

**2. 删除冗余文件**（详见下表），**artifacts/ 下 7 个产物仅忽略不删**（含 `SRR系统香港本地化部署方案.docx` 等实测产物，仍有对照价值）。

**3. 决策**：用户确认仓库为**私有**，因此 `项目计划/` 26 份文档（含 SRR 客户报价/HKD 金额明细）全部保留随仓推送；本次**只写 .gitignore + 删冗余**，暂不执行 `git init`。

### 改动文件清单

- 新增 `/.gitignore`（根级忽略规则）
- 删除 `XIAONA/`（孤儿嵌套 git 仓库，仅含 `.gitattributes`）
- 删除 `backend/xiaona.db`（陈旧 SQLite，0 引用）
- 删除 `plan_extract.txt`（临时提取稿）
- 删除 9 个 `__pycache__/` 目录

### 验证结论

静态核对通过（按 AGENTS.md 约定不代跑构建、不做容器实测）：

- 待推送清单从 133 → **129 个文件 / 1.85 MB**（backend 57、frontend 41、项目计划 26、cli 2，加 `.env.example`/`AGENTS.md`/`start.py`），与计划预估完全吻合；
- 命中检查全部为 **0**：`.env`、`node_modules`、`frontend/dist`、`artifacts/`、`*.db`、`__pycache__` 均未进入待推清单；`.env.example` 正确保留（1 个）；
- 已确认删除生效：`backend/xiaona.db`、`plan_extract.txt`、`XIAONA/`、`__pycache__` 全部 `Test-Path = False`；
